# START — คำสั่งเริ่มต้นเซสชัน

> ทริกเกอร์: พูดว่า **"run START"** (หรือ "/start") ในตอนเริ่มต้นเซสชัน
> Claude จะดำเนินการตามขั้นตอนด้านล่าง

## ลำดับการบูต

1. อ่าน `CONTEXT.md`, จากนั้น `CLAUDE.md`, `ABOUT-ME.md`, `GLOBAL-INSTRUCTIONS.md`
2. อ่าน `TASKS.md` (active + backlog) และรายการล่าสุดใน `checkpoint.md`
3. รันการสแกนสถานะแบบอ่านอย่างเดียวอย่างรวดเร็ว (ไม่มีการเปลี่ยนแปลง):

- `git -C . log --oneline -5` และ `git status -s` — คอมมิตล่าสุด + ไฟล์ที่มีการเปลี่ยนแปลง
- `docker compose ps` — สถานะความสมบูรณ์ของบริการ (หากสามารถเข้าถึง Docker ได้)
- แสดงรายการสิ่งใหม่ๆ ใน `INPUTS/`

1. สร้าง **สรุปแบบสั้น <10 บรรทัด**:

- โปรเจกต์ + ระยะ + สถานะ (หนึ่งบรรทัด)
- สรุปสถานะความสมบูรณ์ของบริการ (หรือ "Docker not reachable")
- การเปลี่ยนแปลงที่ยังไม่ได้คอมมิต (หากมี)
- รายการ backlog 3 อันดับแรกจาก `TASKS.md`
- หนึ่งการดำเนินการถัดไปที่แนะนำ

1. ถามว่า: **"What are we doing today?"** — จากนั้นรอ

## กฎระหว่างการทำ START

- อ่านอย่างเดียวเท่านั้น ห้ามแก้ไข, ห้ามคอมมิต, ห้ามรีสตาร์ท
- ปฏิบัติตามกฎเหล็ก (Ironclad Rules) และค่าเริ่มต้นด้านความปลอดภัยโดยตลอด
- ทำให้สั้นกระชับ — นี่คือการปฐมนิเทศ ไม่ใช่รายงาน

## นามแฝงแบบด่วนที่ฉันอาจใช้

- `run START` → ลำดับการทำงานนี้
- `daily briefing` → `TEMPLATES/daily-ops-briefing.md`
- `incident <desc>` → `TEMPLATES/incident-response.md`
- `status report` → `TEMPLATES/weekly-status-report.md`
- `checkpoint` → ต่อท้ายรายการใหม่ที่ลงวันที่ใน `checkpoint.md` (ถามก่อน)
