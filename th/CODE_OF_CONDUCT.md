# แนวทางปฏิบัติและข้อตกลงสำหรับผู้ร่วมสมทบ (Contributor Covenant Code of Conduct)

## คำมั่นสัญญาของเรา

ในฐานะสมาชิก ผู้ร่วมสมทบ และผู้นำ เราขอให้คำมั่นสัญญาว่าการมีส่วนร่วมในชุมชนของเราจะเป็นประสบการณ์ที่ปราศจากการคุกคามสำหรับทุกคน ไม่ว่าจะเป็นเรื่องของอายุ ขนาดของร่างกาย ความทุพพลภาพที่มองเห็นได้หรือมองไม่เห็น ชาติพันธุ์ ลักษณะทางเพศ อัตลักษณ์และการแสดงออกทางเพศ ระดับของประสบการณ์ การศึกษา สถานะทางเศรษฐกิจและสังคม สัญชาติ รูปลักษณ์ภายนอก เชื้อชาติ วรรณะ สีผิว ศาสนา หรืออัตลักษณ์และรสนิยมทางเพศ

เราขอให้คำมั่นสัญญาที่จะปฏิบัติและมีปฏิสัมพันธ์ในแนวทางที่ก่อให้เกิดชุมชนที่เปิดกว้าง เป็นมิตร มีความหลากหลาย ครอบคลุม และมีสุขภาพดี

## มาตรฐานของเรา

ตัวอย่างของพฤติกรรมที่ส่งเสริมสภาพแวดล้อมเชิงบวกสำหรับชุมชนของเรา ได้แก่:

- การแสดงความเห็นอกเห็นใจและความมีน้ำใจต่อผู้อื่น
- การเคารพต่อความคิดเห็น มุมมอง และประสบการณ์ที่แตกต่างกัน
- การให้และการยอมรับข้อเสนอแนะเชิงสร้างสรรค์อย่างมีวุฒิภาวะ
- การยอมรับผิดและขอโทษต่อผู้ที่ได้รับผลกระทบจากข้อผิดพลาดของเรา รวมถึงการเรียนรู้จากประสบการณ์นั้นๆ
- การให้ความสำคัญกับสิ่งที่ดีที่สุดไม่เพียงแต่สำหรับตัวเราเองในฐานะบุคคล แต่เพื่อชุมชนโดยรวม

ตัวอย่างของพฤติกรรมที่ไม่สามารถยอมรับได้ ได้แก่:

- การใช้ภาษาหรือภาพที่มีลักษณะทางเพศ และความสนใจหรือการเข้าหาในเชิงชู้สาวทุกรูปแบบ
- การก่อกวน (Trolling) การดูถูก หรือการแสดงความคิดเห็นในเชิงเหยียดหยาม รวมถึงการโจมตีบุคคลหรือทางการเมือง
- การคุกคามทั้งในที่สาธารณะหรือในพื้นที่ส่วนตัว
- การเผยแพร่ข้อมูลส่วนบุคคลของผู้อื่น เช่น ที่อยู่หรือที่อยู่อีเมล โดยไม่ได้รับอนุญาตอย่างชัดแจ้ง
- พฤติกรรมอื่นๆ ที่สามารถพิจารณาได้อย่างสมเหตุสมผลว่าไม่เหมาะสมในสภาพแวดล้อมทางวิชาชีพ

## ความรับผิดชอบในการบังคับใช้

ผู้นำชุมชนมีหน้าที่รับผิดชอบในการชี้แจงและบังคับใช้มาตรฐานพฤติกรรมที่ยอมรับได้ของเรา และจะดำเนินการแก้ไขที่เหมาะสมและยุติธรรมเพื่อตอบสนองต่อพฤติกรรมใดๆ ที่พวกเขาเห็นว่าไม่เหมาะสม เป็นการคุกคาม ก้าวร้าว หรือเป็นอันตราย

ผู้นำชุมชนมีสิทธิ์และความรับผิดชอบในการลบ แก้ไข หรือปฏิเสธความคิดเห็น การส่งรหัส (commits) โค้ด การแก้ไขวิกิ ปัญหา (issues) และการมีส่วนร่วมอื่นๆ ที่ไม่สอดคล้องกับแนวทางปฏิบัตินี้ และจะสื่อสารเหตุผลสำหรับการตัดสินใจกลั่นกรองเมื่อมีความเหมาะสม

## ขอบเขต

แนวทางปฏิบัตินี้มีผลบังคับใช้ในทุกพื้นที่ของชุมชน และยังมีผลบังคับใช้เมื่อบุคคลหนึ่งๆ ทำหน้าที่เป็นตัวแทนของชุมชนอย่างเป็นทางการในพื้นที่สาธารณะ ตัวอย่างของการเป็นตัวแทนชุมชนของเรา ได้แก่ การใช้ที่อยู่อีเมลทางการ การโพสต์ผ่านบัญชีโซเชียลมีเดียทางการ หรือการทำหน้าที่เป็นตัวแทนที่ได้รับแต่งตั้งในกิจกรรมทั้งทางออนไลน์และออฟไลน์

## การบังคับใช้

สามารถรายงานกรณีของพฤติกรรมที่ไม่เหมาะสม การคุกคาม หรือพฤติกรรมที่ไม่สามารถยอมรับได้อื่นๆ ไปยังผู้นำชุมชนที่รับผิดชอบในการบังคับใช้ การร้องเรียนทั้งหมดจะได้รับการทบทวนและสืบสวนอย่างทันท่วงทีและยุติธรรม

ผู้นำชุมชนทุกคนมีหน้าที่ผูกพันที่จะต้องเคารพความเป็นส่วนตัวและความปลอดภัยของผู้รายงานเหตุการณ์ใดๆ

## แนวทางการบังคับใช้

ผู้นำชุมชนจะปฏิบัติตามแนวทางผลกระทบต่อชุมชนเหล่านี้ในการกำหนดผลที่ตามมาสำหรับการกระทำใดๆ ที่พวกเขาพิจารณาว่าละเมิดแนวทางปฏิบัตินี้:

### 1. การแก้ไข

**ผลกระทบต่อชุมชน**: การใช้ภาษาที่ไม่เหมาะสมหรือพฤติกรรมอื่นๆ ที่ถือว่าไม่มีความเป็นมืออาชีพหรือไม่เป็นที่ต้อนรับในชุมชน
**ผลที่ตามมา**: คำเตือนที่เป็นลายลักษณ์อักษรและเป็นส่วนตัวจากผู้นำชุมชน ซึ่งให้ความชัดเจนเกี่ยวกับลักษณะของการละเมิดและคำอธิบายว่าเหตุใดพฤติกรรมดังกล่าวจึงไม่เหมาะสม อาจมีการร้องขอให้กล่าวคำขอโทษต่อสาธารณะ

### 2. การตักเตือน

**ผลกระทบต่อชุมชน**: การละเมิดผ่านเหตุการณ์เพียงครั้งเดียวหรือการกระทำต่อเนื่อง
**ผลที่ตามมา**: คำเตือนพร้อมผลที่ตามมาสำหรับพฤติกรรมที่ยังคงดำเนินต่อไป ห้ามมีปฏิสัมพันธ์กับบุคคลที่เกี่ยวข้อง รวมถึงการมีปฏิสัมพันธ์ที่ไม่ได้ร้องขอกับผู้บังคับใช้แนวทางปฏิบัติ เป็นระยะเวลาที่กำหนด ซึ่งรวมถึงการหลีกเลี่ยงการมีปฏิสัมพันธ์ในพื้นที่ของชุมชนรวมถึงช่องทางภายนอก เช่น โซเชียลมีเดีย การละเมิดข้อกำหนดเหล่านี้อาจนำไปสู่การแบนชั่วคราวหรือถาวร

### 3. การแบนชั่วคราว

**ผลกระทบต่อชุมชน**: การละเมิดมาตรฐานชุมชนอย่างร้ายแรง รวมถึงพฤติกรรมที่ไม่เหมาะสมอย่างต่อเนื่อง
**ผลที่ตามมา**: การถูกแบนชั่วคราวจากการมีปฏิสัมพันธ์หรือการสื่อสารสาธารณะทุกรูปแบบกับชุมชนในช่วงระยะเวลาที่กำหนด ไม่อนุญาตให้มีการปฏิสัมพันธ์สาธารณะหรือส่วนตัวกับบุคคลที่เกี่ยวข้อง รวมถึงการมีปฏิสัมพันธ์ที่ไม่ได้ร้องขอกับผู้บังคับใช้แนวทางปฏิบัติ ในช่วงเวลานี้ การละเมิดข้อกำหนดเหล่านี้อาจนำไปสู่การแบนถาวร

### 4. การแบนถาวร

**ผลกระทบต่อชุมชน**: การแสดงรูปแบบของการละเมิดมาตรฐานชุมชน รวมถึงพฤติกรรมที่ไม่เหมาะสมอย่างต่อเนื่อง การคุกคามบุคคลใดบุคคลหนึ่ง หรือความก้าวร้าวต่อหรือการดูถูกกลุ่มบุคคลต่างๆ
**ผลที่ตามมา**: การถูกแบนถาวรจากการมีปฏิสัมพันธ์สาธารณะทุกรูปแบบภายในชุมชน
