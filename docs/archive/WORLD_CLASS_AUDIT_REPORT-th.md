## 2. Verified correct — no changes needed

บริเวณข้อกำหนดภาคบังคับเหล่านี้ได้รับการตรวจสอบและพบว่าเป็นไปตามข้อกำหนดแล้วจากผลงานก่อนหน้าในเซสชันนี้; จึงไม่มีการปรับเปลี่ยนเพิ่มเติม

- **Full-fleet KPI visibility (10 devices, OK/IDLE/NO_DATA):** Manufacturing และ Andon ล้วนใช้ `LEFT JOIN` จากตาราง `public.devices` (รูปแบบของ `v_machine_spc_fleet` ใน migration 042) ดังนั้นเครื่องจักร LDI ทั้ง 10 เครื่องที่ลงทะเบียนไว้จะถูกเรนเดอร์เป็นแถว/ไทล์ (tile) เสมอ โดยสามารถแยกสถานะ OK/IDLE/NO_DATA ได้อย่างถูกต้อง ยืนยันผลแบบสดผ่านภาพหน้าจอ (8 ไทล์สถานะ OK, 2 ไทล์เป็น NO_DATA ในช่วงเวลาที่ไม่มีข้อมูลรายงานเข้ามาจริง)
- **RCA panel correctness (both RCA panels, Manufacturing + Engineering Analytics):** หมวดหมู่ (ผ่าน `v_ldi_alarm_category` migration 036), การเปรียบเทียบกับเส้นฐาน (baseline comparison), Lift (เปอร์เซ็นต์ช่วงแจ้งเตือน ÷ เปอร์เซ็นต์ฐาน), จำนวนเหตุการณ์/ตัวอย่าง, และค่าความมั่นใจ (Confidence) ปรากฏครบถ้วนและถูกคำนวณอย่างถูกต้องจากการอ้างอิงรหัสเตือน 5 หลักของจริงและการแยกข้อมูล flag ผ่าน `v_ldi_alarm_context` (migration 045)
- **Per-panel SQL discipline:** ทุกพาเนลที่ระบุขอบเขตเวลาจะใช้ `$__timeFilter`; การแบ่งระดับ CAGG เป็นไปตามสัญญาที่ระบุไว้ในเอกสาร (`ldi_data_1m` ≤6 ชั่วโมง, `ldi_data_15m` 6 ชั่วโมง–2 วัน, `ldi_data_1h` >2 วัน, และใช้ raw `ldi_data` สำหรับการค้นหาค่าล่าสุดเท่านั้น); ไม่พบข้อความสั่งคิวรีซ้ำซ้อน; ตัวแปรวันที่ฮาร์ดโค้ด (`'2000-01-01'`) ตัวเดียวที่มีนั้นเป็นพารามิเตอร์เริ่มต้น (origin parameter) ที่ถูกต้องสำหรับ `date_bin()` โดยจับคู่กับ `$__timeFilter` เสมอ ไม่ใช่เป็นตัวกรองเวลาขอบเขต (filter bound)
- **Data Readiness dashboard:** มีเจตนาสแกนข้อมูลแบบเต็มรูปแบบ (เพื่อการวินิจฉัยคุณภาพข้อมูลรอบโลก/ช่องว่างการแมป ไม่ใช่มุมมองการผลิตสด) — ทุกคิวรีดังกล่าวถูกทำเครื่องหมายด้วย `NO_TIMEFILTER_INTENTIONAL` ซึ่งเป็นรูปแบบการยกเว้นตามที่ระบุในเอกสารเพื่อให้ Linter ของระบบงบประมาณคิวรียอมรับ เลย์เอาต์ถูกจัดโครงสร้างเป็นตาราง 24 คอลัมน์ตามลำดับที่สะอาดตา ไม่พบช่องว่างหรือส่วนซ้อนทับในความละเอียดเป้าหมายทั้ง 3 ระดับ การจัดรูปแบบข้อความ/หน่วยวัด/จุดทศนิยม/เกณฑ์ได้รับการปรับปรุงให้ถูกต้องแล้ว (กำหนดเวลาเป็นชั่วโมงสำหรับเมทริกซ์อายุ, กำหนดความครอบคลุมเป็นเปอร์เซ็นต์, และแมปสี NO_DATA เป็นสีเทาอย่างสม่ำเสมอ)
- **Typography/units/decimals/axis:** สุ่มตรวจดูค่าตัวเลข/สถิติของเซ็นเซอร์และตาราง PE/JE ของ Machine Snapshot พบว่า °C, %RH, kPa, mm/s, mm, mJ/cm², µm ใช้รหัสหน่วย Grafana ที่ถูกต้องและใช้ทศนิยมในระดับที่เหมาะสม (1–3 ตำแหน่ง) ซึ่งตรงกับความละเอียดที่แท้จริงของเซ็นเซอร์ LDI
- **Andon at 1280×720:** ยืนยันผ่านระบบการตรวจสอบการถดถอยอัตโนมัติ (automated regression) ด้านล่างว่าสามารถแสดงผลได้สมบูรณ์โดยไม่ต้องเลื่อนหรือล้นขอบจอ

โค้ดสีได้ถูกบันทึกและล็อกไว้ในเอกสาร `../architecture/GRAFANA_DESIGN_SYSTEM.md` §2.1a:
