# Decision Matrix

> การตัดสินใจเชิงปฏิบัติการใดที่แต่ละแดชบอร์ดมีอยู่เพื่อรองรับจริง ๆ และใครเป็นเจ้าของ รวบรวมเมื่อวันที่ 14 ส.ค. 2026, ขั้นตอนการรวบรวมหลักฐาน ข้อมูลเจ้าของจาก `OWNERSHIP.md`; จำนวนแผง/ข้อความจุดประสงค์จาก `DASHBOARD_INVENTORY.md` (สร้างขึ้นอัตโนมัติ ห้ามแก้ไขไฟล์นั้นด้วยตนเอง -- ไฟล์นี้เป็นการวิเคราะห์ที่เขียนด้วยตนเองต่อยอดจากไฟล์นั้น)
>
> แดชบอร์ดที่ไม่มีการตัดสินใจที่ชัดเจนในที่นี้ คือแดชบอร์ดที่ไม่ควรมีอยู่ หรือจำเป็นต้องเขียนขึ้นมาก่อนที่จะเชื่อถือได้

## Cross-cutting findings from building this matrix

- **ไม่มีแดชบอร์ดใดที่ขาดการตัดสินใจ** ทั้ง 15 รายการจับคู่กับคำถามที่แท้จริงที่มีคนถาม สิ่งนี้ไม่ได้รับประกันว่าจะเกิดขึ้นในตอนแรก -- คุ้มค่าที่จะระบุเนื่องจากอาจเป็นไปในทางตรงกันข้ามได้
- **สองแดชบอร์ด ("Manufacturing Command Center" และ "Operator Andon Board") ทั้งสองตอบคำถาม "สายการผลิตเป็นอย่างไร" สำหรับกลุ่มเป้าหมายที่แตกต่างกัน (หัวหน้ากะ เทียบกับ ผู้ปฏิบัติงานบนพื้นที่)** ไม่ซ้ำซ้อนกัน -- แดชบอร์ด Andon ตั้งใจให้ไม่มีการโต้ตอบ/บนผนังทีวี ในขณะที่ Command Center รองรับการเจาะลึก ทำเครื่องหมายการจับคู่นี้อย่างชัดเจนเพื่อไม่ให้ผู้ตรวจทานในอนาคตผสานรวมเข้าด้วยกันโดยไม่ได้ตั้งใจ
- **"Alarm Console" เป็นแดชบอร์ดเดียวในที่เก็บข้อมูลนี้ที่มีการเขียน** (ไปยัง `ldi_alarm_lifecycle`) แดชบอร์ดอื่น ๆ ทั้งหมด รวมถึง "Ingestion Latency" เป็นแบบอ่านอย่างเดียว นี่เป็นขอบเขตความน่าเชื่อถือที่มีความหมายซึ่งคุ้มค่าที่จะให้มองเห็นได้ -- มีพื้นผิวการเขียนเพียงหนึ่งเดียว ไม่ใช่สิบสี่
- **ความเป็นเจ้าของในปัจจุบันคือคนเดียว** (`@PATTANAKORN025` สำหรับทุกแดชบอร์ด ในทั้งสองโดเมน) การแยกโดเมนใน `OWNERSHIP.md` เป็นขอบเขตสำหรับเจ้าของคนที่สอง_ในอนาคต_ ไม่ใช่หลักฐานของการมีอยู่ในปัจจุบัน -- อย่ากล่าวอ้างเกินจริงถึงความพร้อมสมบูรณ์ขององค์กรที่ที่เก็บข้อมูลนี้ยังไม่มี
