# 1. Record Architecture Decisions

Date: 2026-08-26

## Status
Accepted

## Context
We need to record the architectural decisions made on this project. Without a historical record, new team members lack context on why certain technologies (Node-RED, TimescaleDB) were chosen over alternatives.

## Decision
We will use Architecture Decision Records (ADRs) to document significant architectural choices.

## Consequences
We will maintain these in `docs/architecture/decisions/`.
