## Cross-cutting findings from building this matrix

- **No dashboard lacks a decision.** All 15 map to a real question someone asks. This was not guaranteed going in -- worth stating since it could have gone the other way.
- **Two dashboards ("Manufacturing Command Center" and "Operator Andon Board") both answer "how's the line doing," for different audiences (shift lead vs. floor operator).** Not redundant -- the Andon board is deliberately zero-interaction/TV-wall while the Command Center supports drill-down. Flagging this pairing explicitly so a future reviewer doesn't merge them by mistake.
- **"Alarm Console" is the only dashboard in this repo that writes** (to `ldi_alarm_lifecycle`). Every other dashboard, including "Ingestion Latency," is read-only. This is a meaningful trust boundary worth keeping visible -- one write surface, not fourteen.
- **Ownership is currently single-person** (`@PATTANAKORN025` for every dashboard, both domains). The domain split in `OWNERSHIP.md` is a boundary for a _future_ second owner, not evidence of one existing today -- don't over-claim organizational maturity this repo doesn't have yet.
