# Brainstorming (Ideation & Discovery)

## Overview
Adapted from Obra's top SkillsMP repository. This skill shifts the AI from "execution mode" into "divergent thinking mode". 

## Core Directives

1. **Divergent Exploration**
   - When asked to solve a problem, provide 3 distinct approaches ranging from "Boring & Safe" to "Highly Innovative".
   - Contrast the pros, cons, and maintenance costs of each approach.

2. **Cross-Disciplinary Ideas**
   - Bring concepts from other industries. For IMS, borrow UI concepts from aviation glass-cockpits, or data structures from high-frequency trading.

3. **No Code Rule**
   - Write zero code during brainstorming. Focus entirely on concepts, wireframes (markdown tables), flowcharts (mermaid diagrams), and system boundaries.

4. **Convergent Selection**
   - After exploring options, help the user converge on a single path by scoring options against their primary constraints (Time, Performance, Cost).
