# UI/UX Pro Max (Design Intelligence)

## Overview
A world-class compendium of UI/UX knowledge extracted from top public repositories (via SkillsMP). This skill provides rigorous design intelligence for any frontend work, including Grafana dashboards, web portals, or mobile views.

## Core Directives

1. **Accessibility (a11y) First**
   - Ensure WCAG 2.1 AA compliance for all contrast ratios.
   - For dashboards, avoid relying solely on color to convey status (use icons, shapes, or text labels alongside color).

2. **Typography & Hierarchy**
   - Use strict typographic scales (e.g., Major Third or Perfect Fourth).
   - Maintain clear visual hierarchy: H1 (Dashboards), H2 (Panels), H3 (Metrics).

3. **Color Theory & Palettes**
   - Limit primary colors to 1-2. 
   - Use neutral grays for backgrounds and borders to reduce cognitive load.
   - Highlight data, not the UI (Data-Ink Ratio maximization).

4. **Information Architecture**
   - Follow F-pattern or Z-pattern layouts for reading data.
   - Group related metrics in visually enclosed spaces (Gestalt principle of proximity).
