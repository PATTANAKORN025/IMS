# 无指责事故回顾模板 (Blameless Post-Mortem)

> **核心理念**: 我们假设每个人都利用当时拥有的信息做出了最好的决定。回顾的目的是调查*系统*，而不是*个人*。

## 事故详情
- **日期**: YYYY-MM-DD
- **作者**: [姓名]
- **状态**: [草稿 / 审查中 / 已发布]

## 1. 摘要 (Summary)
[用一段话概括发生了什么、严重程度以及持续时间。]

## 2. 影响 (Impact)
- **停机时间**: [持续时间]
- **受影响用户**: [数量/百分比]
- **数据丢失**: [是/否 - 详情]

## 3. 根本原因 (Root Cause)
[导致事故发生的系统性底层缺陷 (建议使用 5 Whys 法)。]

## 4. 时间线 (Timeline)
- `10:00 UTC` - 中断开始
- `10:05 UTC` - 警报触发

## 5. 预防行动项 (Action Items)
- [ ] 修复 A (负责人)
- [ ] 增加监控 B (负责人)
