# 数据治理与合规政策 (Data Governance)

## 1. 数据分类 (Data Classification)
- **公开 (Public)**: 系统架构文档、通用架构。
- **内部 (Internal)**: 机器配置、标准遥测数据。
- **机密 (Confidential/PII)**: 操作员 ID、员工班次日志、内部 IP 地址。

## 2. PII 掩码与隐私 (PDPA/ISO 27001)
- 注入警报的操作员 ID 必须在长期存储中进行掩码或假名化处理。
- 原始遥测数据日志必须在 90 天后自动过期。连续聚合 (自动清除 PII) 保留 3 年。

## 3. 访问控制 (RBAC)
- **NOC 操作员**: Grafana 只读权限。
- **工程师**: 仪表板编辑权限，禁止直接访问数据库。
- **管理员**: 直接数据库访问 (通过 PgBouncer 日志审计)。
