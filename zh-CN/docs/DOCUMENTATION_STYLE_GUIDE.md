# 文档编写规范 (Style Guide)

所有 IMS 文档必须遵守以下 Hyper-scaler 标准：

## 1. "自动清晰" 规则 (Auto-Clarity)
剔除废话。删除所有无意义的填充词。直奔技术主题。

## 2. 使用主动语态 (Active Voice)
- **不好**: 仪表板被脚本重新加载。
- **好**: 脚本重新加载仪表板。

## 3. 使用 GitHub 警报 (Alerts)
可视化地突出显示关键信息：
- `> [!NOTE]` 用于背景说明。
- `> [!WARNING]` 用于具有破坏性的操作。
- `> [!IMPORTANT]` 用于核心要求。

## 4. 标题层级 (Header Nesting)
嵌套不要超过 H3 (`###`)。如果需要更深的结构，请使用粗体文本或列表。
