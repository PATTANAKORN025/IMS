# 第 2 阶段 — 世界级 LDI 仪表板加固：基准报告

> **已归档 — 历史快照，日期为 2026-08-05。** 并非动态文档；以下数字（仪表板数量、迁移数量、面板数量等）反映了该日期的系统状态，并且相对于当前系统已知是过时的。根据 docs/archive/README.md 保留为历史记录。有关当前信息，请参阅 docs/architecture/ARCHITECTURE.md 和 docs/architecture/DASHBOARD_INVENTORY.md。

基准在 2026-08-04 在进行任何第 2 阶段更改之前捕获（参阅
`phase2-baseline-metrics.md`）。本报告将该基准与完成全部 10 个第 2 阶段工作流之后的状态进行比较，每个工作流均对照实时数据进行了验证并单独提交（参阅 `main` 上的 git 日志 `13b0317..1380e82`）。

**关于“P95 渲染 < 300ms”的诚实范围说明：** 这是作为查询时间预算 (服务器端 SQL 执行) 来强制执行的，而不是完整的浏览器绘制时间 (网络 + Grafana 面板挂载 + React 渲染)。此代码库中不存在完整的端到端渲染时间测试框架；构建一个需要使用本次未构建的浏览器端计时工具 (例如 Playwright + CDP 网络计时)。所有采样查询的测量值均远低于 300 毫秒；由于此处未捕获到 Grafana/网络开销，实际的屏幕上准备就绪的面板时间会稍长一些。

## 5. 设计系统

- `docs/GRAFANA_DESIGN_SYSTEM.md` 的范围从 3 个仪表板 (NOC/Engineering/Capacity) 扩展到全部 9 个，正式将 LDI 仪表板现有的赛博朋克调色板 (§2.1a) 记录为原始 NOC 调色板的公认同类版本，而不是强制对已被验证的大约 230 个面板进行大规模的重新着色。
- 协调了 33 个预先存在的散乱颜色实例 (大小写形式如 `#00E5FF`、`#EF4444`、`#FACC15`、`#22C55E`)，使其与主要 LDI 约定保持一致 —— 真正的漂移，有些是在本次会话中引入的，现在一致了。
- `dashboard-linter.js` 中的 `ALLOWED_HEIGHTS` 被扩展 (`1,4,5,6,8,10,16`)，以匹配第 5.2 节中规范的 KPI 统计数字高度 (h=4) 和仪表高度 (h=6)，两者现在都在活跃使用中。
